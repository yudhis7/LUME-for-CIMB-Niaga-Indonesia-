First build of **Lume for CIMB Niaga**: the full console as native desktop apps. Runs offline, with sample data for the 8-week pilot.

**Windows 10/11:** `Lume-for-CIMB-Niaga.exe` (single file) or `Lume-for-CIMB-Niaga-Windows.zip` (with install notes). Needs the WebView2 Runtime, which is already on almost every Windows 10/11 PC.

**macOS 14 Sonoma or later:** `Lume-for-CIMB-Niaga-macOS.zip`, a universal app for Apple Silicon and Intel.

The builds are not code-signed yet, so the first launch shows a security prompt:
- Windows: *More info → Run anyway*
- Mac: *System Settings → Privacy & Security → Open Anyway*

The web version is in `web/dist/lume-cimb-niaga.html`.
